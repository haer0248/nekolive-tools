# 雲端儲存
> 2026/08/07 更新

1. 打開任一小工具頁面，調整設定後按「儲存並套用設定」。
2. 複製頁面上「OBS 瀏覽器來源網址」，貼到 OBS 的瀏覽器來源，只需要貼這一次。
3. 之後要改設定，直接回到這個網頁改，OBS 裡的畫面會自動更新（雲端同步已設定的情況下）。
4. 如果要在另一台電腦、另一個瀏覽器分頁編輯同一份設定，把「配對碼」複製過去、貼上並按「套用」即可連動。
5. 換電腦或重灌 OBS 前，建議先用「匯出設定」存一份 JSON 備份，之後用「匯入設定」還原。

**請不要洩漏您的配對碼給所有人，若不慎洩漏請於任一設定頁面重新生成！**
